## 不承認理由の分析

「有用性の低いコンテンツ」は、技術的な不備ではなく内容面の判定。初回審査時のサイトは、開設当日・全21ページ・本文1,000〜1,300字/ページ・執筆者や出典の表示なし・ヘッダーナビやコラム一覧なし、という状態で、ツール系サイトが「計算機だけ」と見なされやすい典型パターンだった。

## 実施した対応

### コミット `7c0e4f4` — コンテンツの増補

- コラム13本を各2,800〜4,000字に増補（具体例・計算例・比較表・落とし穴・背景の説明。言い換えによる水増しはしない）
- ツール8ページの解説に「使い方」「計算例（2026年の実在日付で検算済み）」「こんなときはどうする？」を追加。計算ロジックは無変更
- 共通部品を新設: `ArticleMeta`（執筆者・公開日・更新日）、`Sources`（参考資料・出典）、`DayCountFigure`（初日算入/不算入の SVG 図）、`ColumnLayout`（コラム用レイアウト。Article/FAQ の JSON-LD 付き）
- 出典は `src/lib/site.js` の `REFS` に集約（e-Gov 法令検索、内閣府、国立天文台、消費者庁、国民生活センター）。URL の実在を確認済み
- 運営者情報に「運営者について」「執筆・編集の方針」「情報の更新について」「広告について」を追記
- プライバシーポリシーに AdSense の Cookie・オプトアウト、GA、お問い合わせ情報、著作権、制定日・更新日を追記
- 校閲で見つけた誤りを修正（昭和→平成換算式の符号、改元日の表、クーリングオフの曜日説明、元日の扱い、2月29日生まれの回数 など）

### コミット `84aebc0` — 構造の整備と重複解消（3周の監査）

第1周（構造・技術）
- ヘッダーナビ（ツール／コラム／運営者情報／お問い合わせ）
- コラム一覧ページ `/column/` を新設（テーマ別3グループ。`COLUMNS` / `COLUMN_CATEGORIES` を `site.js` で管理）
- 全ページにパンくず（`Breadcrumb` + BreadcrumbList JSON-LD）
- 404 ページ（`src/pages/404.astro`）。`wrangler.jsonc` に `not_found_handling: "404-page"` を追加
- `public/ads.txt`、OGP 画像 `public/og-default.png`、`og:url` / `twitter:card`
- ツールページに WebApplication JSON-LD、サイトマップに lastmod、404 をサイトマップから除外、404 に noindex
- モバイルで表がはみ出さないよう `.milestones` を横スクロール化（375px 幅で全ページ確認）
- お問い合わせページを充実（受付内容・添えてほしい情報・お答えできないこと）
- title 40字以内・description 120字以内に調整、プライバシーの Google 広告設定 URL 更新と GA オプトアウト追記

第2周（コンテンツ・ポリシー）
- ツール⇔コラムで丸ごと重複していた表・段落を5組解消（六曜／祝日／生後日数／クーリングオフ／営業日）。役割分担: ツール＝使い方・数え方・計算例、コラム＝制度の背景・実務
- 主題から外れた汎用的な節を削除または日付に結び付けて書き直し（結婚記念日の呼び名一覧、法要当日の進行、はがきの書き方、履歴書マナー、入籍の一般論）
- 出典が空だったページに追加（民法143条、母子保健法）。お宮参りの日数表記を統一
- 執筆者に肩書き、運営者情報に「検証体制（自動テスト50件）」と「更新履歴」

第3周（最終レビュー）
- 全ページの日付・曜日・回忌年・改元日など205項目を検算 → 全件一致
- 早生まれの説明の矛盾、特商法の引用表現、関連リンクのラベル食い違い、同一文の繰り返し、図のキャプション不一致を修正
- コラム Article JSON-LD に image を追加

## 今後の流れ

1. 審査結果を待つ（数日〜2〜4週間）。この間はサイト構成の大きな変更を避ける（記事追加は可）
2. 待機中: Search Console でサイトマップ再送信、トップと `/column/` の URL 検査→インデックス登録リクエスト
3. 承認された場合: 広告ユニットを作成し、記事の可読性を損なわない配置を設計（`Base.astro` の head には審査コード設置済み）
4. 不承認だった場合: 理由を確認のうえ、記事の追加（20〜30本が目安）、運用期間の積み上げ（開設から3か月以上）、検索流入の確保を順に進める
